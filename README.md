# GCB Ecosystem Accountability

This repository is the execution + accountability system for building a monetized ecosystem around the Goldstonian Concordance Bible (GCB) to fund ministry expansion, training, and (eventually) church acquisition/turnaround.

## What success looks like
- Consistent weekly execution (content, funnel, offer, partnership)
- A measurable revenue ladder (digital → membership → certification → licensing)
- Documented decisions, risks, and learnings
- A repeatable operating system

## Quickstart (weekly)
1. Open this week's log in `/logs/weekly/`
2. Update the SCOREBOARD
3. Execute the 4 weekly commitments:
   - Content batch
   - Funnel improvement
   - Offer build/sale
   - Partnership outreach

## Files
- NORTH_STAR.md — mission, constraints, non-negotiables
- ROADMAP.md — phased plan
- SCOREBOARD.md — KPI tracking
- ACCOUNTABILITY.md — rules + cadence
- FUNNEL.md — lead magnet, email sequence, CTAs
- OFFERS.md — product ladder + pricing
- CHURCH_ACQUISITION.md — future capital plan + criteria
